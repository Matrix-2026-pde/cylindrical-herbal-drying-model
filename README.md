# 基于柱坐标热质耦合与动边界的中药材热风烘干过程建模

本项目是数学建模竞赛成果，研究圆柱形中药材在时变热风环境下的温度场与含水率场演化，并比较固定边界与收缩动边界对烘干过程的影响。

## 摘要

热风烘干过程中的温度与水分演化由表面对流换热换质与内部扩散共同控制，属于典型的非稳态热质耦合问题。本文以一段圆柱形药材为对象，首先在轴对称条件下将三维传热-传质问题退化为二维 `(r, z)` 模型；随后通过逐位误差分析与特征尺度论证，说明轴向影响可忽略，并将后续问题统一为一维径向有限体积模型。

问题一采用二维轴对称有限体积模型，温度方程使用 Crank-Nicolson 格式，水分方程采用向后欧拉格式并通过 Picard 迭代处理非线性扩散系数。结果表明，1800 s 时表面温度升至 36.79 °C、表面含水率降至 1.51 kg/kg，而中心仍接近初值 2.55 kg/kg；轴向影响主要局限在端面附近薄层。

问题二引入随温度和含水率变化的经验物性参数，采用交替迭代求解双向耦合的温度场与水分场。3 h 时中心温度升至 49.85 °C，表面与中心含水率分别降至 1.01 kg/kg 和 1.77 kg/kg，干燥前沿逐步向内部推进。

问题三以全场最大含水率低于 0.15 kg/kg 作为干透判据，得到固定尺寸模型的烘干时长约为 57.47 h；前 12 h 中心含水率由 2.55 kg/kg 快速降至 0.46 kg/kg，之后进入较长的尾段干燥阶段。

问题四通过随体坐标 `ξ = r/R(t)` 将收缩的物理区域映射到固定计算域，并采用动边界模型描述失水收缩。半径由 2.0 cm 收缩至 1.2 cm 后，烘干时长约为 51.09 h，相比固定尺寸模型缩短约 61%，相比问题三净减少约 6.38 h。

灵敏度分析显示，传质系数 `h_m` 是影响水分演化的主要因素，平衡含水率影响较小；长时程环境外推和传质系数取值是烘干时长的主要不确定来源。空间与时间双收敛分析，以及多套独立离散实现的交叉验证，表明数值误差不影响四位小数级结果。

## 方法概览

1. 建立圆柱形药材的热传导-水分扩散耦合方程及对流边界条件。
2. 先求解二维轴对称问题，再用轴向误差与特征尺度分析验证降维依据。
3. 使用有限体积法、隐式时间离散和 Picard 迭代处理变物性非线性。
4. 对收缩问题采用随体坐标映射，将动边界问题转化为固定计算域上的求解问题。
5. 通过网格/时间步收敛、敏感性分析和独立离散实现交叉验证结果。
